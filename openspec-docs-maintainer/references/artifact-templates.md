# 持久化产物模板

Runbook 和 Incident 按需创建，不生成空目录或占位文档。创建后在 references 中登记 R 索引。

## Runbook

路径：`.claude/runbooks/<topic>.md`

```markdown
# <操作名称>

## 适用范围

<何时使用、何时不适用>

## 前置条件

<权限、环境、输入和安全检查>

## 操作步骤

<可重复执行的顺序>

## 验证

<成功判据、命令和预期结果>

## 失败处理

<常见失败、停止条件和诊断入口>

## 回滚

<恢复步骤；不可回滚时明确说明>
```

## Incident

路径：`.claude/incidents/YYYY-MM-DD-<topic>.md`

```markdown
# <事件名称>

## 影响

<用户、系统、数据和持续时间>

## 时间线

<发现、响应、恢复和确认节点>

## 触发与根因

<触发条件、根因和促成因素>

## 检测与恢复

<如何发现、如何恢复、哪些保护失效>

## 后续动作

<关联 K、D、M、I、change 或 Runbook>

## 证据

<日志、命令、版本、路径和外部资料>
```

普通测试失败不创建 Incident。一次性命令不创建 Runbook。
