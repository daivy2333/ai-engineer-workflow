# BetterMd

8 条硬约束 + 1 份禁用词清单。目标：写准而非写多。

## 规则

**1. 反膨胀**

能删的字、句、段必删。不因"看起来更完整"而生造段落，不堆砌过渡与总结。删掉后不影响理解的内容一律删除。

**2. 直白**

见下方禁用词清单，触犯即改写。

**3. 三段式优先**

段落按"陈述 → 论据 → 限定"展开。无限定条件或论据时不强写。

**4. 结构从内容出发**

标题直接说事。层级 ≤ H2。

**5. 无源不写**

无来源则不写；不量化则用定性表达。禁止编造 URL、数据、引用、commit、行号。

**6. 代码可验证**

涉及编程项目问题的，或者与实际代码相关的必须给可点击 permalink，当添加代码commit链接更能解释说明问题的时候就应该要加。无法定位时，在编写完成后提醒用户"需人工核对"，不用在文档进行显式标注。

**7. 短句优先**

单段 ≤ 5 句；单句 ≤ 30 字。

**8. 信息量守恒**

与原文信息量或者编写文档依据的上下文的信息量相比，拒绝因为丢失实质内容，而造成过度精简，不应该造成信息丢失。保留：关键事实、数字阈值、边界条件、原因、后果等。

## 禁用词清单(只是例子，核心是无必要不修饰，更不能夸张修饰)

**修辞性词汇**

终极 / 核心 / 本质 / 范式 / 深刻 / 颠覆 / 革命性 / 重构 / 抓手 / 赋能 / 闭环 / 痛点 / 赛道 / 一句话总结 / 沉淀 / 澄清 / 真实 / 直接

**AI 过渡句式**

让我们 / 值得注意的是 / 总的来说 / 综上所述 / 首先...其次...最后 / 显而易见 / 不言而喻 / 众所周知 / 毋庸置疑 / 一方面...另一方面 / 最直白 / 最不饶弯子

**装饰性套话**

笔者认为 / 在当今时代 / 随着...的发展 / 总而言之 / 不可否认
